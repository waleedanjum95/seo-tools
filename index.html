About Robots.txt Generator

A robots.txt file instructs web robots (typically search engine crawlers) about which pages or files they can or can't request from your site. This prevents crawl budget waste on private admin panels or temporary directories.

How to use: Define the targeted user-agent (use * for all bots) and specify paths you wish to block. Generate and save the file as robots.txt in your web root folder.
